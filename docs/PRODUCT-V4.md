2. Final UI Design System

Visual Direction

Editorial Typography × Contemporary Minimalism.

参考现代杂志、数字词典及专业效率工具。

视觉要求：

* 冷白、中性灰、黑色为基础。
* 不使用大面积奶油色或米黄色。
* 默认强调色为 Acid Lime 青柠绿 #D9F36B。
* 同一主题使用单一主强调色。
* 不在一个页面中同时使用过多鲜艳颜色。
* 保留其他可选强调色主题，如矢车菊蓝、淡紫、橙色。
* 语义状态颜色仅在必要时使用。
* 避免过度卡片化、渐变、装饰性阴影及幼稚游戏化。
* 强调网格、对齐、留白、排版和细分隔线。

Base colors:

* Background: #F8F9FA
* Surface: #FFFFFF
* Primary text: #191919
* Secondary text: #686868
* Border: #E0E2E4
* Default accent: #D9F36B

Geometry

* Main blocks: 0–4px radius.
* Cards: 0–6px radius.
* Buttons: 2–4px radius.
* Inputs: 2–4px radius.
* 尽量减少圆角与嵌套卡片。
* 使用边框、间距与排版建立视觉层次。

Typography — Updated

全局文字比此前版本稍微加粗，保持清晰的字重层次，不是将所有文字统一设置为 Bold。

字体及目标字重：

* English vocabulary: Cormorant Garamond, 600.
* English headings: Cormorant Garamond, 600.
* English reading body: Source Serif 4, 500.
* English UI: Manrope, 500.
* Buttons: 600.
* Secondary labels and captions: 500.
* 中文正文、释义、个人笔记：仿宋，优先采用视觉上接近 500 的字重。
* 中文功能界面：系统中文无衬线字体，500。

中文正文默认字体：

font-family: “FangSong”, “仿宋”, “STFangsong”, serif;

不要使用思源宋体作为默认中文阅读字体。

注意仿宋可能只有常规字重。根据实际渲染选择适当方案，避免粗糙的强制加粗。没有合法字体文件时使用系统字体回退，不擅自分发商业字体。

支持：

* 全局字体粗度设置：Regular / Medium / Bold。
* 默认 Medium。
* 字号设置。
* 阅读行距与宽度设置。
* 深色模式。
* 中英文界面切换。
* 强调色主题切换。

通过集中式 CSS design tokens 实现，不逐页面重复硬编码。

3. Vocabulary Library

内置四个核心词库：

* High Frequency 3000
* TOEFL
* IELTS
* GRE（重点）

使用 ECDICT 或其他经过许可证验证的合法数据源。

保留词库导入、批量添加、CSV/TXT/XLSX、阅读生成词库、自定义词库及导出功能。

所有词库共享统一词汇数据库。

同一词元在不同词库中共享单词级学习记录，不重复创建相同单词或重复统计。

GRE 支持优先学习、词频、难度、陌生程度、错误率及复习优先级筛选。

难度信息必须有真实数据或明确计算依据，不能虚构。

Sense-level Learning

新增或完善多义词独立掌握机制。

采用 Word/Lemma 与 Sense 两级数据模型。

Word 层级记录：

* 拼写
* 发音及音标
* 词形变化
* 词库归属
* 单词级笔记
* 拼写学习记录

Sense 层级记录：

* 具体词义
* 词性
* 中英文释义
* 例句
* 搭配
* 释义级笔记
* 独立掌握状态
* 必要的 FSRS 复习记录
* 阅读语境及出现位置

例如 interest：

* 兴趣：已掌握
* 利息：学习中
* 利益：尚未确认

用户可以单独学习、标记、收藏及复习某个释义，不必重新学习整个单词。

阅读查词时支持选择具体释义加入生词本或复习队列。

不要把认识一个释义自动等同于掌握所有释义。

Word-level spelling 与 Sense-level meaning 应合理共享已有学习证据，但不能把一个释义答对自动记为其他释义答对。

共享同一词元、同一释义的跨词库记录；不同释义允许独立调度。

每日学习量及全局统计明确区分独立词元数量与学习卡片/释义数量，避免重复计数。

词典更新时保持稳定的 sense ID 或可迁移映射，避免历史学习记录失效。

如果现有数据模型只有 word-level 状态，使用安全的增量 schema migration 保留已有记录，不重置学习进度。

4. Dictionary & Word Cards

保留离线 ECDICT 词典、Oxford/Cambridge 官方查询入口及可插拔 DictionaryProvider。

默认发音：美音 US。

允许切换英音 UK、重复播放及调整语速。

使用可用的设备 TTS 或合法授权音频。不假设所有设备都支持离线发音。

不使用未经授权的商业词典数据、例句或真人音频。

Default Word Card Fields

默认显示：

1. 英文单词及词性
2. 音标
3. 发音按钮
4. 中文释义
5. 英文释义
6. 个人笔记
7. 例句
8. 常用搭配
9. 词频与难度

5. Onboarding & Daily Learning

首次使用加入可跳过的 Quick Assessment。

支持：

* 认识
* 模糊
* 不认识
* 尚未确认
* 快速筛查
* 批量标记
* 之后继续筛查

不强制完成所有基础词汇测试。

外部词汇量测试不能直接用于推断具体已掌握的单词。

默认每日学习 30 个新词，可调整，包括设为 0。

默认优先处理到期复习，再学习新词。

支持额外学习、暂停新词、临时学习计划、保存未完成学习进度及恢复上次学习。

复习任务过多时，提供减少新词数量的非强制建议。

6. New Word Learning

保持简洁流程：

Recognition → Spelling → Scheduling.

Recognition：

展示单词、释义、音标、发音、例句、搭配及个人笔记。

允许快速标记已认识。

Spelling：

根据中文或英文释义进行拼写测试，提供反馈及重新尝试。

Scheduling：

根据结果进入 FSRS 复习队列。

不强制每个新词经历复杂的听写、辨析、造句等步骤。

对于只需要学习新释义的熟悉单词，重点测试该释义，不无意义地重复已掌握的拼写训练。

7. Intelligent Review

保留 ts-fsrs 智能间隔复习。

默认 Target Retention = 0.90，可在设置中调整。

支持 Again / Hard / Good / Easy。

保留完整复习日志及真实记忆状态。

题型依据历史表现加权随机抽取：

* 英文选中文
* 英文选英文释义
* 中文回忆英文
* 英文释义猜词
* 听音辨义
* 听写
* 拼写
* 语境填空
* 词形变化
* 近义词辨析
* 搭配选择

优先保证基础题型正确、稳定。

多义词题目必须提供足够的语境或明确指定释义，避免多个答案均合理却被判错。

客观题结果和用户自评分开记录，合理映射至 FSRS rating。

数据不足时不得虚构能力掌握度。

不强制依赖 AI API。

8. Reader — Final Requirements

内置阅读器继续作为核心模块。

支持：

* 文本型 PDF
* EPUB
* DOCX
* TXT
* Markdown
* 粘贴文章
* 文件夹、书籍、章节及课程分类

保留阅读词汇提取、词形还原、词频统计、文档专属词库生成及跨词库状态共享。

Desktop Reader Layouts

支持三种布局切换：

1. Side Dictionary：正文 + 右侧词典栏。
2. Popup Dictionary：点击或划词后显示浮窗。
3. Focus Reading：隐藏侧栏，专注阅读，按需查词。

移动端默认使用底部词典弹窗，适配触屏。

切换布局不得丢失阅读位置。

Reading Actions

支持：

* 单词即时查词
* 标记认识、模糊、不认识
* 选择特定释义进行学习
* 加入生词本及自定义词库
* 播放发音
* 添加单词笔记
* 保存单词出现的原句及出处
* 显示/隐藏词汇状态标记
* 正文搜索
* 阅读进度保存
* 上次位置恢复
* 阅读书签
* 整段或选区高亮
* 段落批注
* 查看、编辑及删除已有批注
* 词汇列表筛选及批量操作

阅读高亮、段落批注和书签使用稳定文档位置或可靠锚点，避免刷新、调整字号或同步后错位。

用户导入的私人材料不得未经授权发送给 AI 或第三方解析服务。

9. Notes

保留单词级及释义级笔记。

新增或完善阅读批注与笔记的关联。

单词笔记在普通学习时默认显示，在测试时默认提交答案后显示，可自行设置。

所有笔记支持持久化、自动保存、搜索、编辑、删除、阅读出处和跨设备同步。

不允许同步冲突静默丢失笔记内容。

10. Interaction & Shortcuts

桌面端支持键盘快捷键：

* Space：显示答案或继续
* 1：Again
* 2：Hard
* 3：Good
* 4：Easy
* Enter：提交拼写
* P：播放发音
* N：编辑笔记
* B：收藏
* Esc：关闭弹窗或暂停学习

快捷键根据当前学习阶段启用，防止误操作。

输入框、文本编辑器及笔记编辑时自动停用冲突的全局快捷键。

移动端加入左右滑动卡片操作，保留明确按钮作为替代。

手势不可影响正文滚动、系统返回操作或正常文本选择。支持关闭手势。

补充内容：Study Flow Update — Interleaved Learning & Delayed Recall
修改现有新词学习流程，采用交错学习（Interleaved Learning）与延迟主动回忆（Delayed Active Recall）。
不要使用以下机械流程：
Learn A → Spell A → Learn B → Spell B
也不要先学习全部新词，再集中进行全部拼写测试。
Required Behavior
* 在同一个 Study Session 中动态穿插 Learn 和 Spelling。
* 学习一个新词后，将其加入当前 Session 的短期回忆队列。
* 默认间隔 3–5 个其他学习或测试事件后，再出现该词的拼写测试。
* 间隔适当随机化，不使用完全固定、可预测的顺序。
* 根据单词难度、历史错误及本次学习表现动态调整出现频率。
* 拼写错误后展示正确答案、释义及个人笔记，然后重新加入回忆队列。
* 不要在展示正确答案后立即重复测试同一个单词，除非当前没有其他可用任务。
* 优先穿插其他单词，再次检测错误单词。
* 已经熟悉拼写、仅学习新释义的单词，可以使用对应释义的回忆测试代替拼写。
* Session 即将结束时，处理剩余回忆任务，避免遗漏已经学习但尚未测试的单词。
Session Scheduling
维护轻量的 Session Task Queue，支持：
* New word learning
* Delayed spelling
* Meaning recall
* Incorrect answer retry
* Completed tasks
将新词引入与待回忆任务合理交错，避免一次积累过多未测试的新词。
保存 Session 队列、当前位置、答题结果及未完成任务。退出、刷新、断网或切换设备后，可以恢复学习进度。
FSRS Integration
区分：
* Session-level short-term learning：单次学习中的短期记忆巩固。
* FSRS long-term review：跨天的长期记忆调度。
不要将每一次短期拼写重试机械地记录为一次独立的长期 FSRS 复习。
根据有效学习结果和既定 FSRS 学习阶段更新长期复习状态，避免重复累计学习量或人为高估记忆稳定性。
